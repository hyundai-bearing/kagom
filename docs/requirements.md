# 카곰(가제) 요구사항

2026-11-05 · 작성 junsu kim · 정리 반영: 정비팀 합친 기획(11/4), 운영사무국 답변(11/4)

카곰은 Pleos 차량 신호로 차 상태를 캐릭터 표정·말풍선·음성으로 알려 주고, 물어보면 대답하는 차량용 앱이다.
공개 Pleos API만으로 핵심 기능이 동작하고, 비공개 API와 외부 정비 이력은 확장으로 둔다.

> **이 문서를 읽는 법**
> - 원래 명세의 내용은 그대로 두고, 표마다 **현재 데모** 열을 붙였다. 11/5 구현 후 기준이다.
>   - ✅ 있음 · 🟡 일부 · ⬜ 없음 · ⚠️ 명세와 다르게 만들어져 있음
> - 결정 사항은 맨 위 [결정 사항](#결정-사항)에 모았다. 본문 요구사항 문장도 확정된 결정에 맞게 고쳤다(고친 곳은 *기울임* 표시).

> **11/6 Figma 리빌드 뒤 달라진 점 (2026-11-09 코드 확인)**

### 두 파트 (PART 1 · PART 2)

11/2 「캐릭터 연동 기능·함수·권한」 문서의 구분이다.

| 구분 | 뜻 | 해당 항목 | 카곰 |
|---|---|---|---|
| PART 1 | 차 센서가 지금 상태를 직접 줌 | 연료·배터리 잔량, 엔진오일·브레이크액·미션오일 레벨, 엔진 이상, 워셔액 | 배고픔, 아픔, 얼룩(오일 레벨), 배지 |
| PART 2 | 센서가 없어서 앱이 계산함 (주행거리 + 정비 기록) | 엔진오일 교체 시기, 1만 km 건강검진 | 얼룩(교체 시기), 피곤함 |

같은 단계면 PART 1이 먼저인 이유: 실제 센서가 알려 주는 지금 상태라서다. 정비 시기는 며칠 미뤄도 되는 계산된 일정이다.
예) 연료 15%(PART 1, 권장)와 1만 km 건강검진(PART 2, 권장)이 함께 있으면 **배고픔** 표정을 보여 주고, 건강검진은 배지로 남긴다.

3D 곰 위에 2D로 겹친다. 곰을 옆으로 돌리면 흐려져서 얼굴에서 떨어져 보이지 않는다. 디버그 빌드에서 바로 볼 수 있다.

### 확인 기록

#### 시동·탑승 신호 (Q1)

Pleos Vehicle SDK 2.3.2 클래스를 직접 확인한 결과, **시동(점화) 상태를 알려 주는 공개 API는 없다.** 대신 쓸 수 있는 신호:

| 방법 | SDK | Virtual Console로 시험 | 비고 |
|---|---|---|---|
| **운전석 착석** (채택) | `Seat.getCurrentSeatOccupancy` · `registerSeatOccupancy` (운전석 `SeatArea`) | ✅ Seat Occupancy 카드 | 권한 `CAR_SEATS` |
| 이번 주행 시간·거리가 줄어듦 | `Odometer.getTripCurrentDrivingTime` · `registerTripCurrentDrivingTime`, `getTripCurrentDrivingDistance` | ⬜ 카드 없음 | 실차에서 시동 때 0으로 돌아가는지 확인 필요 |
| 앱 실행 = 시동 (보조) | 없음 | ✅ | 앱을 껐다 켜면 시동으로 잘못 셈 |

#### 주행 판단 (Q2·Q3·Q7)

- 운영사무국 답변(11/5)은 PRIVATE_CAR_SAFETY 사용(개발 가능, 출시·값 제공은 보장 안 함)과 권한 선언만으로 에뮬레이터 개발이 가능하다는 내용이고, CarUxRestrictionsManager는 다루지 않았다. 팀 결정으로 사용한다.
- 에뮬레이터에서 동작 확인: 차량 서비스에 `uxrestriction`·`drivingstate`가 켜져 있고, 현재 주행 상태는 `0`(PARKED). 주행 상태는 기어·속도로 계산되며 Virtual Console에서 둘 다 바꿀 수 있다(속도는 에뮬레이터 활성 시). `android.car.jar`가 Android SDK 35·37에 있다.
- Pleos 공개 SDK에는 **차량 속도 API가 없고** 기어(`Gear.getCurrentGearSelectionState` · `registerGearSelection`, P/R/N/D)만 있다.
- 참고 문서
  - API: [CarUxRestrictionsManager](https://developer.android.com/reference/android/car/drivingstate/CarUxRestrictionsManager) — `getCurrentCarUxRestrictions()`, `registerListener()`, `unregisterListener()` / [CarUxRestrictions](https://developer.android.com/reference/android/car/drivingstate/CarUxRestrictions)
  - 가이드: [Driver distraction guidelines (AOSP)](https://source.android.com/docs/automotive/driver_distraction/guidelines) — 액티비티에 `distractionOptimized` 메타데이터 선언
  - 빌드: `android { useLibrary("android.car") }`
- 에뮬레이터 홈 화면 로그에 현재 앱이 `distractionOptimized: false`로 찍힌다. Q7에 따라 선언한다.

## 구현하며 정한 가정 (11/5)

명세에 없어서 구현할 때 정한 것들이다. 바꾸고 싶으면 알려 주면 된다. 코드 위치는 괄호 안.

| # | 내용 | 이유 |
|---|---|---|
| A1 | **엔진 이상** = Pleos `Safety.hasPowerDownWarningIndicator`(출력 저하 경고) | 공개 SDK에 "엔진 이상" 이름의 API가 없고, 가장 가까운 신호 (`PleosVehicleSignalSource`) |
| A2 | **파랑 배지** = 관찰 단계 (연료·배터리 30%, 오일 교체 10% 남음) | 명세에 파랑의 뜻이 없음 (`StateEngine.badges`) |
| A3 | 연료·배터리 **긴급도 노랑** | 빨강은 "아픔" 표정 전용이라, 빨강이면 배고픔 대신 아픔이 됨 |
| A4 | **엔진오일·미션오일 CRITICALLY_LOW = 빨강**, 브레이크액·미션오일 HIGH = 정상 | 명세에 없음 (`StateEngine.oilBadge`) |
| A5 | 정비 기록이 없으면(모르겠어요·건너뛰기) **0km 기준**으로 계산 | 계산 기준이 필요. 기록을 넣으면 바로 고쳐짐 |
| A6 | 오일 교체: 10% 남으면 관찰, 기한이 되면 권장. 건강검진은 기한이 되면 권장(관찰 없음) | 명세 예시("1만 km 건강검진 = 권장")에 맞춤 |
| A7 | 알림이 동시에 생기면 **가장 중요한 하나만** 말풍선·음성. 이미 떠 있는 더 중요한 말풍선은 덮지 않음. 나머지는 배지로 남음 | 브레이크액 말풍선이 건강검진에 가려지던 문제 (`KagomController.recompute`) |
| A8 | 정차 중 권장·긴급이 처음 생기면 말풍선과 함께 음성도 냄. 주행 중에는 긴급만 | FR-31·FR-32를 정차 중에도 같은 1회 규칙으로 적용 |
| A9 | 시동 회차: 앱 시작 2.5초 뒤 착석 신호가 없거나 이미 앉아 있으면 1회차, 이후 운전석이 비었다가 앉을 때마다 +1 | Q1 (`KagomController.start`) |
| A10 | 제때 정비: 관찰·권장 단계에서 기록했고, 기한 뒤 1,000km·31일 안 | D16 (`KagomController.saveRecord`) |
| A11 | 건강검진 체크리스트 항목은 **예시** (매회 5가지 + 2회차마다 필터 교체 + 4회차마다 브레이크액) | 실제 점검 항목 확정 필요 (`StateEngine.checkupChecklist`) |
| A12 | 브레이크액·미션오일·엔진 [정비했어]는 기록만 남김. 배지는 센서 값이 정상이 돼야 사라짐 | 센서 값을 앱이 바꿀 수 없음 |

## 범위와 전제

### 우선순위

| 우선순위 | 뜻 |
|---|---|
| 필수 | 1차 마감 시연에 반드시 들어감. 공개 API와 앱 자체 계산만 씀 |
| 선택 | 시간이 되면 넣음. 공개 API지만 동작 확인이 더 필요 |
| 확장 | 개발 단계 시도 또는 발표의 향후 계획. 비공개 API·외부 연동 |

### 전제

- **대상**: Pleos Connect가 동작하는 차량. 기준 차종은 2026 그랜저(GN7) 가솔린·하이브리드. 전기차는 엔진오일 항목을 숨김
- **사용자**: 개인 차량 운전자 1명. 정비 지식이 없어도 카곰의 말만 보고 판단할 수 있어야 함
- **허용 SDK**: Vehicle · FusedLocation · NaviHelper · TTS · STT (공모전 개발 환경). **11/5 팀 결정: 지금 쓸 수 있는 API·SDK(Android 차량 API 포함)는 모두 사용 가능**
- **권한**: 매니페스트에 선언하면 에뮬레이터 개발·테스트에 별도 승인이 필요 없음 (운영사무국, 11/4)
- **PRIVATE_CAR_SAFETY**: 개발 과정에서 쓸 수 있지만, 실제 값 제공과 앱마켓 출시는 보장되지 않음 (운영사무국, 11/4)
- **정비 기록**: 차량별 정비·검사 이력을 가져올 공개 API가 없어 사용자 입력으로 받음

### I. 지역 도전과제 (11/5 추가, 서울·인천 먼저)

구·군마다 랜드마크 3곳을 정하고, 3곳을 모두 방문하면 그 구·군을 지도에 색칠한다. 서울·인천은 시 전체가 한 칸이라 구·군 단위로 칠하고 시별 진행률을 함께 보여 준다.

  - 랜드마크: 구마다 3곳을 골라 좌표를 OSM Nominatim에서 받고, 그 구 경계 안인지 자동 검사했다. 같은 구 안에서 너무 가까운 곳(한 번 주차로 둘이 인정되는 곳)은 다른 곳으로 바꿨다.
  - 반경: 기본 400m, 넓은 곳(공원·대학·공항)은 500m~1.2km.
- **저장**: 방문한 랜드마크 id와 날짜만 저장한다. 위치 기록은 남기지 않는다 (NFR-07).
- **권한**: `pleos.car.permission.FUSED_LOCATION`은 런타임 권한이라 첫 실행 때 묻는다. 거절해도 다른 기능은 그대로.
- **시연**: [시연] 메뉴 "서울/인천 다음 랜드마크로 (D)" → "P단 (주차)". 또는 `adb emu geo fix <경도> <위도>` + `--es demo_gear P`.

## 데이터와 외부 연동

### 저장 데이터 (차량 안)

| 이름 | 필드 | 설명 |
|---|---|---|
| 정비 기록 (항목마다 한 줄) | `itemId` · `lastOdoKm` · `lastDate` · `usedRecommendedOil` | `engine_oil`, `checkup`, `tire_rotation`, `brake_fluid` … 추천 오일 여부는 엔진오일만 |
| 앱 설정 | `engineType` · `severeMode` · `voiceOn` | 가솔린 / 하이브리드 / 전기차, 가혹 조건, '카곰 음성' |
| 보상 | `onTimeCount` · `titles` | 제때 정비 횟수, 받은 칭호 |
| 지역 도전과제 | 랜드마크 id → 방문 날짜 | 위치 자체는 저장하지 않음 |
| 알림 기록 | 상태별 마지막 단계 · 음성 낸 시동 회차 | 같은 알림을 반복하지 않기 위한 값. 시동 회차는 운전석 착석(없으면 앱 실행)으로 셈 |
| 검사 일정 (선택) | `firstRegistDate` 또는 `lastInspectDate` | FR-57을 넣을 때만 (1차 제외) |

### Pleos SDK

| SDK | 쓰는 곳 | 권한 | 확인 상태 |
|---|---|---|---|
| Vehicle · Fuel / EvBattery | FR-02, FR-03 | CAR_ENERGY | 공식 소스 확인. EvBattery SOC는 현재 데모에서 동작 확인 |
| Vehicle · Safety | FR-04 | CAR_SAFETY | 공식 소스 확인, 시연은 Mock |
| Vehicle · Odometer | FR-05, FR-14, FR-15, FR-51 | CAR_DRIVE | 공식 소스 확인, 콜백 이름은 다른 팀 코드 기준 |
| Vehicle · Seat (운전석 착석) | FR-32, FR-33 | CAR_SEATS | SDK 클래스 확인, Virtual Console 카드 있음 |
| Vehicle · Tire / Telltales | FR-07 | PRIVATE_CAR_SAFETY | 개발 단계만, 값 제공 미보장 |
| Android · CarUxRestrictionsManager | NFR-01, FR-31, FR-44 | — (`useLibrary("android.car")`) | 에뮬레이터에서 서비스 동작 확인 |
| Vehicle · Gear | FR-80 | CAR_DRIVE | `registerGearSelection`, `GEAR_PARK`. 에뮬레이터에서 동작 확인 |
| FusedLocation 1.1.3 | FR-80 | FUSED_LOCATION (런타임 권한) | `registerFusedLocationCallback`. `adb emu geo fix`로 위치가 바뀌는 것 확인 |
| TextToSpeech | FR-30 ~ FR-34, FR-42 | TTS_SERVICE | 공식 문서 확인, `Mode.ON_DEVICE` |
| SpeechToText | FR-41 | STT_SERVICE + RECORD_AUDIO | 다른 팀 코드 기준, 문서 확인 필요 |
| NaviHelper | FR-60 ~ FR-62 | NAVI_CUSTOM_MAP · NAVI_ROUTE | 화면 종류 이름은 다른 팀 코드 기준 |

호출 순서: `Vehicle(context)` → `initialize()` → `check…Capabilities` → `get…` → `register…` → `unregister…` → `release()`.
메서드 전체 표와 코드 예시는 합친 PDF 10~14쪽.

**Virtual Console로 바꿀 수 있는 값** (에뮬레이터 `/vehicle/catalog` 기준 확인): Battery SOC·Energy·Capacity, 주행 가능 거리, **Odometer**, **기어**, 브레이크 페달, 조향, **경고등(Telltales)**, **좌석 착석**, 도어·창문·조명, 공조, 크루즈 컨트롤 등. 엔진오일·브레이크액·미션오일·워셔액 카드는 없어서 FR-71 Mock이 필요하다. 타이어 공기압 카드도 없다. 값을 바꾸려면 Virtual Console의 에뮬레이터가 켜져 있어야 한다(꺼져 있으면 `emulator_inactive`).
