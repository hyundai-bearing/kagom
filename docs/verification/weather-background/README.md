# 움직이는 홈 배경 확인 (2026-11-13)

Pleos Connect v2.1.0 에뮬레이터(2560×1440), 디버그 빌드. 캡처는 앱 창만 잘랐다 (Full 1682×1210, Split 슬롯 841×1210).
움직임은 캡처로 남지 않아 아래 "움직임"에 따로 적었다.

| 파일 | 본 것 |
|---|---|
| `full-meadow.jpg`, `full-sunset.jpg`, `full-coast.jpg` | 맑은 들판(= 오늘 날씨의 맑음)·노을 언덕·동해 바다, `--es demo_background BG-01|BG-02|BG-03` (Full) |
| `full-cloudy.jpg`, `full-rain.jpg`, `full-snow.jpg` | 오늘 날씨, `--es demo_weather cloudy|rain|snow` (Full) |
| `full-thunder.jpg` | 천둥번개, 번개가 치는 순간 (연속 캡처 가운데 한 장) |
| `full-closet.jpg` | 옷장 배경 탭 (동해 바다를 잠근 저장 데이터로 봄): 미리보기에 장면이 깔리고, 카드는 멈춘 그림, 잠긴 동해 바다는 회색 + 자물쇠 |
| `full-demo-panel.jpg` | 시연 패널 "날씨"·"배경 미리보기" 묶음. 날씨 제목 옆에 실제로 받아 온 날씨가 보인다 |
| `split-coast.jpg`, `split-sunset.jpg`, `split-clear.jpg`, `split-rain.jpg`, `split-snow.jpg` | Split 슬롯. 헤더 글자가 구름 위에서도 읽힌다 |
| `split-driving-still.jpg` | 동해 바다 + 기어 D: 멈춘 그림 |

움직임:

- 정차(기어 P, 동해 바다): 1초 간격 캡처 두 장에서 앱 창의 픽셀이 달랐다 (925,100개 가운데 16,678개).
- 주행(기어 D, 동해 바다): 2초 간격 캡처 두 장에서 앱 창의 픽셀이 모두 같았다 (다른 픽셀 0개). 천둥번개에서도 같았다 (번개는 번쩍임 없이 보이는 채로 멈춘다).
- 주행 중에 시연 날씨를 바꿔도 배경은 그대로이고 기어 P에서 바뀐다 (첫 판에서 확인, 그 뒤로 이 부분 코드는 그대로다).
- 프레임 시간(`dumpsys gfxinfo`, 6초): 천둥번개 Full 370프레임·중간값 22 ms·99% 32 ms, 동해 바다 Split 366프레임·중간값 24 ms·99% 46 ms.
- 실제 날씨: 시연 값을 끄면 에뮬레이터 위치로 MET Norway에서 받은 값이 보인다 (같은 날 "흐림" → "맑음" → "흐림"으로 바뀌는 것을 봤다).
- 옷장: 오늘 날씨 [자세히] 설명에 "날씨 자료: MET Norway"가 보이는 것을 앞선 판에서 확인했다 (마지막 판에서는 캡처를 다시 찍지 않았다).

못 본 것: 실제 날씨로 비·눈·천둥번개가 들어오는 경우(시연 값으로만 봤다), 위치가 없거나 통신이 끊긴 기기, 30분 뒤 다시 받아 오는 것, 세로 폰 에뮬레이터, 실제 기기의 프레임 시간, 잠긴 동해 바다의 [자세히] 팝업(카드의 회색 처리만 봤다).
